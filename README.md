# Java Chat Application

## Description
This project is a chat application developed in Java that supports both group chat and individual (private) messaging. It includes a user interface styled with CSS.

## Features
- Group chat functionality
- One-to-one private messaging
- Client-server architecture
- Styled user interface (CSS)

## Technologies Used
- Java
- Socket Programming
- Multithreading
- CSS (for UI styling)

## How to Run
1. Compile the files:
   javac *.java

2. Run the server:
   java Server

3. Run the client:
   java Client
